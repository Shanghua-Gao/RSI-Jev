Typed decisions

RSI-Jev playground

Give the model context, fill in typed questions, and inspect the decisions with their probabilities. Every released version answers the same question, so you can see where they differ.

 

01State

Everything the decision depends on. The model reads this and nothing else — paste a ticket, an alert, a diff, or leave the example.

Versions Input format

All questions share this context and are answered independently, so asking ten costs one read of the state.

02Questions

What you want decided about it. Each question is answered on its own, and comes back as a probability rather than a sentence.

Yes / nonoul one probability that the answer is yes
Pick onechoice a probability for every option you list
Rate itscore a probability for each level, and the weighted position on the scale

03Run decision

Editing does not re-run the model: a pass costs one read of the state per version, so you spend it when you choose to.

⌘⏎ Inputs changed. Run again.

Results

One row per option. Each selected version draws its own bar, so where two releases disagree is visible without reading the numbers.

 

04API request

POST /demo/compare

JSON sent when you press Run. Copy it to call the same endpoint from your own code. The released server speaks the Jev contract at POST /v1/systemone; this page adds the version list.
