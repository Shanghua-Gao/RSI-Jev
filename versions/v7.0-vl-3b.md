# RSI-Jev v7.0-VL 3B

*Describes release v7.0-VL 3B · updated 2026-11-06*

**v7.0-VL 4B, cut at layer 20.** The first 20 of v7.0-VL 4B's 32 decoder layers, with its
layer-20 decision head as the main head and its layer-16 head as an early exit. Nothing was
retrained: every weight is v7.0-VL 4B's, and every answer is the one v7.0-VL 4B gives at
`--effort medium` (bitwise, on 4,001 Decision Index rows). The option echo, the
prefix-bidirectional attention, images and the API are v7.0-VL's.

On the public Decision Index 0.3 it scores **60.01** (v7.0-VL 4B: 60.61), with a median latency
of 19.6 ms against 29.4 ms for the 4B on the same GPU.

v7.0-VL 3B is a System One model: one forward pass, no generated reasoning, a probability for
every option. `effort` sets how many layers that one pass uses (16 or 20), not how many tokens it
writes; it writes none.

It is a 3B model, named as Qwen names its models: **3.30B parameters**, all of which the package
ships and runs — the 20 decoder layers (2.23B), the token embeddings (0.64B), the vision tower
(0.33B), the main decision head (0.05B) and the early-exit head (0.05B). The checkpoint is
self-contained.

Checkpoint: [shgao/rsi-jev-v7.0-vl-3b](https://huggingface.co/shgao/rsi-jev-v7.0-vl-3b) · this record: `versions/v7.0-vl-3b.md`

## 1. The task

Unchanged from [v7.0-VL](v7.0-vl.md#1-the-task): a state (text, optionally up to four images),
one or more typed questions, a probability for every option in one forward pass, and
`usage.depth`, the layer each question was answered at.

## 2. How the model is built and trained

From the v7.0-VL 4B package (Hugging Face tag `v7.0-VL`), with no training:

1. **The tower** keeps decoder layers 1–20 and the final norm; layers 21–32 are dropped. The
   token embeddings and the vision tower are unchanged.
2. **The heads.** v7.0-VL 4B's layer-20 head becomes the main head; the layer-16 head stays an
   early exit; the layer-32 head is dropped. All three heads were trained in v7.0-VL's one run
   ([v7.0-VL's record](v7.0-vl.md#2-how-the-model-is-built-and-trained), §2); the early-exit
   heads trained on detached states, so the first 20 layers are exactly what the layer-20 head
   was trained to read.
3. **Calibration** is v7.0-VL's per-exit temperatures (log T 0.28 at layer 16, 0.22 at 20).
   `auto`'s threshold at layer 16 is v7.0-VL's, 0.80; a question that does not stop there
   answers at 20. The default single threshold is v7.0-VL's 0.95.

Training sources, licences and the training run are v7.0-VL 4B's; see its record.

Why 20: v7.0-VL 4B at `medium` (layer 20) reads within 0.007 of layer 32 on the suite and scored
59.18 against 59.76 for `high` on the 16k Decision Index sample in its record (§5), at about two
thirds of the latency.

## 4. Results

### 4.1 Against v7.0-VL 4B

The 3B's layers 1–20 and its two heads are v7.0-VL 4B's, so its text reads are v7.0-VL 4B's
per-exit outputs at layers 16 and 20 under the 3B's policies, from the same evaluation dump as
the 4B's record (fp32, ECE at the served temperatures). `low` and `high` stop at layers 16 and
20; `auto` stops at 16 when the calibrated top probability reaches 0.80, else at 20. KoBBQ and
CLINC150 come from the release gates on the same per-exit outputs, the images from the 3B package
served by this repository's code (images run all 20 layers).

### 4.2 External: Decision Index

**Decision Index 0.3, public index: 60.01** (raw 69.76). Full run of the 3B package served by
this repository's code at the default effort on one RTX PRO 6000 Blackwell, 140,178 requests,
coverage 1.0, all answered, none truncated: knowledge and reasoning 40.9, language 62.1,
retrieval 67.7, tools 81.9, arts 48.8; 60.00 with the rows that also appear in our training data
left out. v7.0-VL 4B scores 60.61 on the same index with the same code, v6.1-VL 4B 50.98.

**Decision Index 0.2.1, full run: 58.84** (all 150,759 requests answered, nothing cut;
knowledge 37.1, language 63.0, retrieval 67.7, tools 81.9, arts 44.5), the same with the
overlapping rows left out. v7.0-VL 4B: 59.61.

The loss against the 4B is in knowledge and reasoning (40.9 against 42.4 on 0.3, 37.1 against
39.1 on 0.2.1, the 4B's areas from its record); the other areas are within 0.5.

### 4.3 Calibration

The temperatures are v7.0-VL's. Layer 20 was v7.0-VL's best-calibrated exit (final ECE 0.028
against 0.039 at layer 32); see §4.1 for the 3B's policies.

## 5. Speed and serving

Over the full Decision Index 0.3 run (one RTX PRO 6000 Blackwell, bf16, default effort) the
median latency is 19.6 ms and the 95th percentile 151 ms; v7.0-VL 4B on the same setup: 29.4 ms
and 236 ms.

Serving is v7.0-VL's: the package switches the option echo and the prefix-bidirectional
attention on itself (`meta.json` `serve_env`), the linear-attention kernels run at one fixed
configuration each (no autotuning; the same request gets the same answer), inputs up to 32,768
tokens with nothing cut, up to 5,120 options, own-token option pooling, no prefix or document
cache. `--effort medium` and `--effort high` both answer at layer 20.

The API returns a probability *and* a `confidence`, and they are different numbers: `confidence`
is the peak statistic Jev documents, `(K * p_max - 1) / (K - 1)`. Route on the probability of the
option you intend to act on. The response also carries `usage.depth`, the layer each question was
answered at.

## 6. Limitations

- Everything in [v7.0-VL's limitations](v7.0-vl.md#6-limitations), except that the 3B has no
  layer 32: questions with images run 20 layers.
- Knowledge-heavy questions lose most from the cut: MMLU-Pro reads 0.469 against 0.502 for the
  4B at layer 32.
- The thresholds were chosen for the 4B's three exits, not refit for two.

## 7. How it got here

No new arms: the 3B is a cut of v7.0-VL 4B, chosen after the 4B's release from its per-exit
reads (§2). The checks behind it:

- the 3B at `high` against v7.0-VL 4B at `medium`, both served by this repository's code: 4,001
  of 4,001 Decision Index rows give bitwise identical answers;
- the 3B package loads with an empty Hugging Face cache and no network, and answers as above;
- the full Decision Index runs in §4.2 and the images in §4.1, on the release package.

## 8. Corrections to v7.0-VL's record

- §4.2 of v7.0-VL's record gives Decision Index 0.3 public 60.63 and 0.2.1 59.63, read on the
  package as served just before release (fp32 tower, before the kernel configurations were
  fixed). The released files (bf16 tower, fixed kernels, this repository's code) read **60.61**
  and **59.61**; that run is the one submitted to the Decision Index.
